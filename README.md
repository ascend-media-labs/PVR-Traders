# PVR Traders

Official web application for PVR Traders — Premium Construction Materials Supplier (Cement, Iron & Steel, River Sand & M-Sand, Stone Chips Aggregates, and Solid Cement Bricks).

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS & Custom Design System
- **Icons**: Lucide React
- **Build**: Vite & Nitro

## Development

You need Node.js (v18+) and npm.

```sh
npm install
npm run dev
```

## Production Build & Test

```sh
npm test
npm run build
```
